# @hermes/web

The Next.js **web dashboard** for Hermes Workspace OS.

Run locally: `pnpm --filter @hermes/web dev` (or `just web`) → http://localhost:3000.

## Milestone 1 status
Skeleton only: the app shell, a landing page that doubles as a **stack health
dashboard** (pinging the API), a `/health` route, and unit tests for the health helpers.
The full dashboard and project workspace arrive in Milestone 10. See
`docs/PROJECT_BIBLE/07_Interface/*`.
